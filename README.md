# Clash Meta Router

Генератор конфигураций Clash Meta / Mihomo с несколькими прокси,
группами подключений и гибкой маршрутизацией трафика.

## Основные возможности

- несколько VPN-серверов в одном YAML;
- VLESS Reality;
- Hysteria2;
- другие протоколы Clash Meta;
- группы прокси;
- автоматическая маршрутизация;
- отдельные прокси для российских сайтов;
- основной зарубежный маршрут;
- возможность легко добавлять и удалять серверы.

## Статус

Проект находится в разработке.
